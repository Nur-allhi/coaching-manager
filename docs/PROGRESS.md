## P0 Foundation

### P0-1 — Scaffold — **Done**

**Acceptance:** all scripts run clean on an empty app. **Met.**

**What changed**

- Project created at `coaching-center-manager/` with pnpm 10.34.9.
- Vite 8 + React 19 + TypeScript 5.9 (strict, see D-001) + ESLint 10 (flat config) +
  Prettier 3 + Tailwind CSS v4 + shadcn/ui (Radix, `radix-nova`).
- Folder layout from PLAN.md section 5 in place: `src/app`, `src/core/*`, `src/modules/*`,
  `docs/`, `e2e/`, `scripts/`.
- Scripts: `dev`, `build`, `preview`, `typecheck`, `lint`, `lint:fix`, `format`,
  `format:check`, `test`, `test:watch`, `coverage`, `e2e`, `e2e:ui`, `e2e:report`,
  `check` (typecheck + lint + test + build).
- Vitest (jsdom) + React Testing Library wired to `src/test/setup.ts`.
- Playwright (Chromium) configured against `vite preview` on port 4173.
- `vite-plugin-pwa` with a Workbox service worker, `autoUpdate` registration, and a
  manifest with generated 192/512/maskable icons plus `apple-touch-icon`.
- Self-hosted fonts bundled locally: Noto Sans (Latin variable) and Noto Sans Bengali
  (400/500/700) — no remote font request.
- 55 shadcn primitives in `src/components/ui/` (button, input, form fields, dialog,
  dropdown, select, table, tabs, sidebar, chart, calendar, command, toaster, and more).
- `src/app/App.tsx` renders a minimal scaffold landing screen. The real shell, router,
  registry, error boundary, single-tab lock and i18n come with P0-6.

**Tests added**

- `src/app/__tests__/App.test.tsx` — renders the scaffold heading and the offline note.
- `e2e/smoke.spec.ts` — the shell loads, and the page issues **no** request to any host
  other than its own origin (guards the "no network calls at runtime" rule).

**Known gaps**

- `src/components/ui/` and `src/hooks/use-mobile.ts` are generated by the shadcn CLI and are
  excluded from ESLint and Prettier. `use-mobile.ts` was rewritten to use
  `useSyncExternalStore` because the generated version broke the `react-hooks/set-state-in-effect`
  rule.
- The `form` shadcn component does not exist in the `radix-nova` registry; forms will use React
  Hook Form + Zod with the `field` primitives (D-003).
- No database, no worker, no data layer yet — that is P0-2 onward.
- Chromium is installed for Playwright. Firefox and WebKit are not yet installed; P0-2 needs
  them for the cross-browser acceptance line (`pnpm exec playwright install firefox webkit`).
- Dark mode tokens exist in CSS but no theme toggle is wired (not in v1 scope until P6-5).

**Next:** P0-2 — spike sqlite-wasm in a Worker with the `opfs-sahpool` VFS; create a table,
insert, reload the page, data persists, and `exportBytes`/`importBytes` round-trip. Findings
go to `docs/DECISIONS.md`.
